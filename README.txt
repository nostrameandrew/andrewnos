MEMORY BREAKOUT: 50 YEARS
=========================

HOW TO PLAY
  Double-click index.html. It opens in any modern browser (Chrome, Safari, Edge, Firefox).
  No internet connection or install is needed.

HOW TO ADD YOUR PHOTOS AND WORDS (no coding needed)
  1. Photos: put your 50 photos in the "photos" folder, named 01.jpg, 02.jpg ... 50.jpg.
     Photo 50 is the grand finale (the football photo). The title screen tells you how many
     photos it found and lists any that are missing.
     If a photo is .png or .jpeg, change its file name in content.js to match.
     Tip: photos around 1600px wide load fastest on phones.
  2. Words: open content.js in any text editor (TextEdit, Notepad, VS Code). Edit:
       - photo captions (one per photo)
       - chapter titles
       - the Dad-le answer and hint
       - the Spelling Bee pangram (must use exactly 7 different letters) and center letter
       - the trivia questions
       - the 5 bonus messages
       - the final note, signature and headline
     Save the file and reload the game.

TESTING TIP
  The game saves progress in the browser. To start fresh while testing, use
  "New Game" on the title screen.

SENDING IT TO DAD
  Send the WHOLE folder (zip it): index.html, content.js, words.js, the js folder and the
  photos folder must stay together. You can also upload the folder to any static web host
  (for example the same place his games are hosted) and send him the link. That is
  the best way to play on a phone or tablet.

CONTROLS
  Breakout:  mouse / arrow keys / drag your finger to move. Click, tap or Space to launch.
             P or Esc to pause. M to mute (or the speaker button).
  Bonus games: instructions are shown before each one.

ENDLESS MODES
  After the finale, "∞ Endless Modes" unlocks (title screen, Album, and the final collage):
   - Endless Memory Breakout: new rounds forever, each hiding one of the 50 memories
     (all 50 appear once, shuffled, before any repeat). Guys and score carry over,
     bonus guy every 5 rounds.
   - Endless Galaxy Guard: wave after wave of aliens, getting faster and tougher, with new
     enemy types joining as you go and a Mothership every 5 waves. A lost memory comes
     back every 3 waves.
  The best run of each is saved.
